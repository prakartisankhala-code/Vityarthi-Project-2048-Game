# 2048 Game – Java

## Project Overview:

2048 Game is a console-based puzzle game developed using Java. The objective of the game is to combine tiles with the same number until a tile with the value 2048 is created.

The project demonstrates important Java programming concepts such as 2D arrays, loops, methods, conditional statements, switch statements, random number generation, and user input handling.

## Objectives:

* Develop a functional 2048 puzzle game using Java.
* Implement a 4 × 4 game board.
* Allow players to move tiles in four directions.
* Combine tiles with equal values.
* Maintain and update the player's score.
* Generate random tiles after successful moves.
* Detect the winning condition.
* Detect when no more moves are possible.

## Technologies Used:

* Programming Language: Java
* JDK: Java Development Kit
* Input: Java Scanner
* Randomization: Java Random
* Interface: Console / Command Line

## How to Play:

The game starts with two randomly generated tiles.

Use the following keys to move the tiles:

| Key | Movement  |
| --- | --------- |
| `W` | ⬆️ Up     |
| `S` | ⬇️ Down   |
| `A` | ⬅️ Left   |
| `D` | ➡️ Right  |
| `Q` | Quit Game |

When two tiles with the same value collide, they merge into a single tile with their combined value.

### Example

```text
2 + 2 = 4
4 + 4 = 8
8 + 8 = 16
```

Continue merging tiles until you reach **2048**.
